Configurar Google Drive
  1. No Google Cloud Console, crie um projeto e ative a Google Drive API.
  2. Crie uma credencial ID do cliente OAuth do tipo "Aplicativo da Web".
  3. Em "Origens JavaScript autorizadas", coloque o endereço onde esta página está hospedada (não funciona abrindo o arquivo direto do disco).
  4. Cole o ID abaixo. Ele fica salvo só neste navegador.

Sobre o formato e as cores

O formato .PES é proprietário (Brother/Babylock) e não tem especificação pública; a leitura usa o bloco de pontos "PEC" como decodificado por projetos abertos (pyembroidery, libembroidery). As cores vêm do índice de linha gravado no bloco PEC (tabela padrão de 65 cores Brother). Toque numa cor para ocultar ou mostrar aquele bloco. Fontes embutidas e preenchimentos programáveis podem não aparecer.
